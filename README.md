# IBM-Data-Science-Capstone
## SpaceX Falcon 9 First Stage Landing Prediction

### Project Overview

SpaceX has reduced launch costs by developing reusable rockets. One of the key factors contributing to these savings is the ability to recover and reuse the Falcon 9 rocket's first stage.

The objective of this capstone project is to analyze publicly available SpaceX launch data and predict whether the Falcon 9 first stage will land successfully. This prediction can help estimate the potential for first-stage reuse and support launch cost analysis.

### Business Problem

A hypothetical competitor, Space Y, wants to understand SpaceX's launch operations and compete in the commercial space industry. The goal is to gather and analyze launch data, build interactive dashboards, and develop a machine learning model to predict first-stage landing outcomes.

### Project Objectives

- Collect publicly available SpaceX launch data.
- Perform data wrangling and exploratory data analysis.
- Analyze launch sites, payload masses, and launch outcomes.
- Visualize launch data using interactive maps and dashboards.
- Build and evaluate machine learning classification models to predict first-stage landing outcomes.

### Tools and Technologies

- **Python** — Data collection, processing, and analysis
- **Pandas and NumPy** — Data manipulation
- **Requests and BeautifulSoup** — Data collection and web scraping
- **SQL** — Querying and analyzing launch data
- **Matplotlib, Seaborn, and Plotly** — Data visualization
- **Folium** — Interactive maps
- **Scikit-learn** — Machine learning and model evaluation
- **Dash** — Interactive dashboard development

### Learning Outcomes

This project provides hands-on experience in the end-to-end data science workflow, from collecting and exploring data to visualizing insights and building predictive machine learning models.
